# DocuWriter

DocuWriter helps teams generate, manage, and maintain documentation for their software projects. Its core workflow combines Full Tree Documentation, Spaces, and Autopilot.

## What the team gets

Full Tree Documentation analyzes the selected repository source, proposes an outline for the team to review, then generates a connected set of pages about the project. The pages explain architecture, modules, services, APIs, workflows, and implementation details in context. For example, an API is explained alongside the service that owns it. The result is a navigable documentation tree in a Space.

Spaces give teams one place to browse, search, edit, organize, share, and publish those pages, including knowledge added by engineers. A Space can bring documentation from multiple repositories together.

Autopilot watches changes in connected repositories, identifies documentation that may be affected, and drafts focused updates for review. Teams can accept, refine, or reject suggestions, or configure controlled automatic application where appropriate.
