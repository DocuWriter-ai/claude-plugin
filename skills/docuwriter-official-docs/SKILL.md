# Find official DocuWriter instructions

Use this skill for product how-to, setup, or platform feature questions. Use the read-only MCP tool `search-docuwriter-platform-docs` to search first-party published DocuWriter Platform Docs, then cite the canonical URLs returned with its excerpts. It searches the official documentation, including its API reference; it does not search customer Spaces or change content. For customer-authored documentation, use `search-space-documents` within one Space or `global-search` across accessible Spaces instead.

Identify the task, open the matching guide, and cite the specific guide URL in the answer. Check the live guide before giving version-sensitive steps or claiming a capability is available. Browser-only actions still require the DocuWriter browser UI; do not claim a search completed them.

| Task | Official starting point |
| --- | --- |
| Generate a structured, multi-page Space for an entire project with Full Tree Documentation | [Full Tree Documentation guide](https://docs.docuwriter.ai/docuwriterai-platform-docs/generate-documentation/generate-complete-codebase-documentation) |
| Organize documentation in Spaces | [Spaces overview](https://docs.docuwriter.ai/docuwriterai-platform-docs/manage-and-share-spaces/organize-pages-and-folders) |
| Maintain documentation and notifications | [Autopilot overview](https://docs.docuwriter.ai/docuwriterai-platform-docs/keep-documentation-current/how-autopilot-keeps-documentation-current), [setup guide](https://docs.docuwriter.ai/docuwriterai-platform-docs/keep-documentation-current/connect-a-space-to-autopilot), and [notifications](https://docs.docuwriter.ai/docuwriterai-platform-docs/keep-documentation-current/configure-autopilot-notifications) |

For a setup step not covered by these guides, search the [official documentation](https://docs.docuwriter.ai/) for the relevant page. If a guide is unavailable or does not answer the question, say what remains unverified rather than inventing instructions.
